Additionally, I drafted an initial representation schema so we can also see who each source serves and tag content consistently as it's ingested. The fields describe the source itself, not the population.

Representation fields
• Population focus: who the source was developed, adapted, piloted, or intended for.
• Language: language(s) of the source and any reported translation or adaptation.
• Setting: where it was developed or tested, such as community, academic, safety-net, urban, rural.
• Adaptation status: standard, culturally adapted, or resource-constrained.
• Missingness: what the source does not report, so gaps stay visible.
• Presentation coverage: whether the source addresses somatic expression, spiritual or religious framing, migration or acculturation stress, discrimination-related stress, family or relational framing, general cultural considerations, or none reported.

Implementation fields
• Study type, evidence level, and sample size, where applicable.
• Intended use context: in-session support, assessment, or education, kept high-level for now.
